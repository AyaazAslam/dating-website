# Kundana

Premium dating platform frontend for Burundi.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Motion
- React Hook Form + Zod
- Lucide icons

## Key product rules

- Brand: Kundana
- Registration: 5,000 BIF
- Age gate: 18+
- Signup fields: photo, residence, age, gender, contact number, relationship status

## Commands

```bash
npm install
npm run dev
npm run lint
npx tsc --noEmit
npm run build
```

## Deploy

Import this GitHub repository into Vercel and deploy.
